# Рабочий каталог перевода

- `input/` — исходные RTF.
- `output/` — опубликованные переводы RTF и их ревизии.
- `state/` — пользовательская и управляемая память проекта.
- `work/` — манифест, отчеты, транзакции и резервные копии.
- `.codex/agents/` — локальные агенты этого проекта.

Заполните пользовательские области файлов в `state/` до первого запуска. Не меняйте основной текст опубликованного файла во время приемки: добавляйте штатные аннотации RTF либо выделяйте фрагмент в ChatGPT App, выбирайте `Add to chat` и описывайте замечание.
