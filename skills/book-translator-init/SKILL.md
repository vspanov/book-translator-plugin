# Инициализация проекта

Вызов: `$book-translator-init [ПАПКА]`.

1. Определи абсолютный путь. Если путь не указан, используй текущий рабочий каталог.
2. Определи абсолютный путь к `<каталог этого SKILL.md>/../book-translator/scripts/init-project.py` и запусти `python <скрипт> <абсолютный-путь-проекта>`.
3. Покажи созданные каталоги и файлы. Если команда вернула `конфликты_агентов`, перечисли их: пользовательские TOML сохранены. Заменяй каждый такой файл только после точного подтверждения пользователя с `--overwrite-agent ИМЯ.toml`.
4. Предложи заранее заполнить пользовательские области в `state/`.

Инициализатор создает только отсутствующие `input/`, `output/`, `state/`, `work/`, `config.ini`, `progress.json`, `TRANSLATION.md`, маркер схемы и `.codex/agents/`. Он не перезаписывает настройки или state и отказывается автоматически мигрировать проект прежней схемы.
