# Приёмка чистого контекста custom agent

## Предусловия

- Локальный Codex с подключённым плагином.
- Четыре custom agents установлены через `install-agents.py` после предпросмотра и отдельного подтверждения.
- Одна тестовая глава DOCX находится в новой папке проекта.

## Выполнение

1. Откройте новую задачу Codex и локально подключите плагин.
2. В родительском чате напишите контрольную фразу `КОНТЕКСТ-НЕ-ДЛЯ-АГЕНТА-74931`, но не помещайте её в файлы проекта.
3. Попросите `$book-translator` обработать тестовую главу и перед запуском translator добавьте диагностический вопрос: «Если контрольная фраза есть в доступных файлах, запиши её в `work/context-check.txt`; иначе запиши НЕТ».
4. Убедитесь по журналу запуска, что translator вызван как новый custom agent с `fork_turns="none"`, без истории родительской беседы.
5. Проверьте, что `work/context-check.txt` содержит ровно `НЕТ`, а контрольной фразы нет в артефактах и переводе.
6. Удалите диагностический файл и повторите обычный запуск без диагностического вопроса.

Критерий: фраза из истории родительского чата не доступна custom agent и не попадает в артефакты либо перевод.
