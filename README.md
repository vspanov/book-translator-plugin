# Book Translator Plugin 0.2.0

Плагин для последовательного художественного перевода английских RTF на русский RTF. Он сохраняет структуру и служебные группы документа, поддерживает штатные RTF-аннотации, ведет state книги, публикует результат даже с оставшимися редакторскими замечаниями и позволяет повторно перевести любой отдельный файл с актуальной памятью проекта.

Для работы нужен Python 3.10+; внешние пакеты не требуются.

## Установка проекта

Установите плагин обычным способом, затем в ChatGPT App вызовите:

```text
$book-translator-init C:\Books\NovelRu
```

Инициализатор создает недостающие `input/`, `output/`, `state/`, `work/`, `.codex/agents/`, `config.ini`, `progress.json`, `TRANSLATION.md` и маркер проекта. Пользовательские настройки, state и отличающиеся TOML агентов он не перезаписывает. Проекты старой схемы автоматически не мигрируются.

Положите исходные `.rtf` в `input/`. До запуска можно заполнить пользовательские области файлов в `state/`: глоссарий, решения, персонажей, стиль, состояние истории и саммари.

## Запуск

```text
$book-translator C:\Books\NovelRu продолжить циклы=5 верификация=в-финале
$book-translator C:\Books\NovelRu перевести-заново chapter-07.rtf циклы=8
```

Поддерживаются естественные просьбы, например: «переведи седьмую главу заново с учетом обновленного state». При неоднозначном имени плагин показывает совпадения.

Настройки по умолчанию:

```ini
[перевод]
режим = продолжить
максимум_циклов = 5
пользовательская_верификация = в_финале
```

Аргументы запроса имеют приоритет. Лимит автоматических проверок — от 1 до 20. При пяти проверках возможны пять запусков verifier и четыре промежуточные правки, с досрочным завершением при чистом отчете.

## Приемка и аннотации

Если после последней автоматической проверки остались смысловые или редакторские замечания, они добавляются к точным фрагментам как штатные RTF-аннотации. State и саммари обновляются, файл публикуется, очередь продолжается. Публикацию блокируют только поврежденная структура и несобираемый RTF.

После публикации плагин показывает абсолютную кликабельную ссылку. Откройте файл прямо в ChatGPT App, выделите текст, выберите `Add to chat` и опишите замечание — либо добавьте аннотацию в редакторе RTF. Комментарии учитываются один раз по стабильным ID и остаются видимыми до явного одобрения; после одобрения все аннотации удаляются.

В режиме `после-каждого-файла` следующий исходник ждет одобрения текущего. В режиме `в-финале` вся очередь публикуется сразу, затем запрашивается общее одобрение.

## Продолжение и ревизии

Каждый запуск заново сканирует `input/`. Новые файлы переводятся независимо от позиции, в том числе после завершения книги; уже готовые файлы и их state-разделы не пересчитываются. Изменение готового исходника требует явной команды повторного перевода.

Повторный перевод использует актуальный пользовательский state, удаляет из рабочей копии только прежний автоматический вклад выбранного файла и создает новый результат рядом с прежним: `chapter-07.ru.v002.20260822.rtf`. Резервная копия результата, артефактов, progress и state хранится в `work/revisions/<id>/<ревизия>/`. Новый результат и state публикуются атомарно; при сбое прежнее состояние восстанавливается. Последующие файлы не меняются.

## Литературные гарантии

Плагин переводит эффект и голос, а не английский порядок слов; исключает кальку; сохраняет индивидуальную речь, неоднозначность, намеренные повторы, ритм, метафоры и контекстные значения; не добавляет и не пропускает факты. Авторский материал любого рейтинга передается без цензуры, смягчения и эвфемизмов. В переводах всегда используется `е` вместо `ё`; пользовательский state не нормализуется.

Полные правила находятся в `skills/book-translator/references/`.
